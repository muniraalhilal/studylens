# تشغيل StudyLens من VS Code

المشروع يعمل محليًا دون اشتراكات أو مفاتيح API. تحتاجين Python 3.11 أو أحدث واتصالًا بالإنترنت لتنزيل المكتبات أول مرة فقط.

1. افتحي مجلد **StudyLens** في VS Code.
2. افتحي Terminal → New Terminal.
3. على macOS نفّذي:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
cp .env.example .env
python -m uvicorn backend.app.main:app --reload --host 127.0.0.1 --port 8000
```

على Windows، استخدمي:

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
Copy-Item .env.example .env
.venv\Scripts\python.exe -m uvicorn backend.app.main:app --reload --host 127.0.0.1 --port 8000
```

4. افتحي http://127.0.0.1:8000 ثم اضغطي **جرّبي الديمو بدون تسجيل**. تفتح جلسة مستقلة مع الملفات التجريبية تلقائيًا، بلا بريد أو كلمة مرور. إنشاء حساب شخصي ما زال خيارًا محليًا.
5. اضغطي **العربية** لتغيير اللغة واتجاه الصفحة، وزر القمر لتغيير المظهر. يُحفظ اختيارك في المتصفح.
6. اختاري **استكشفي الملفات التجريبية** لإضافة محاضرة عربية عن قواعد البيانات ومحاضرة إنجليزية عن الشبكات.
7. افتحي الملف: الملخص، البطاقات، الاختبار، سؤال الملف، والنص الأصلي كلها تعمل.
8. بعد تسليم الاختبار، تظهر الدرجة والتصحيح وتحفظ النتيجة في صفحة تقدّمي.

## ما الذي يُحفظ؟

الحسابات ونصوص الملفات والنتائج والمراجعات في `data/studylens.db`. تُستخرج النصوص من الملفات؛ لا يتم الاحتفاظ بالملفات الأصلية نفسها. أوقفي السيرفر بـ Ctrl+C وشغليه بالأمر نفسه لاحقًا لاستكمال العمل.

## كيف يعمل الجزء الذكي مجانًا؟

الديمو يستخدم تحليل النص وترتيب الجمل والبحث بالكلمات محليًا. الملخص مقتطفات من الملف، والبطاقات والاختبارات تعتمد على كلمات ناقصة، وإجابة السؤال تعرض مقاطع المصدر مع رقم الصفحة. ليس نموذجًا لغويًا توليديًا ولا يحتاج API. استخدمي في سؤالك كلمات من الملف ولغته نفسها.

ملفات PDF المصورة تحتاج OCR قبل رفعها. تغيير لغة الواجهة لا يترجم محتوى المحاضرة. الملفات المقبولة PDF وPPTX وTXT وMD حتى 10 ميجابايت.

## قاعدة البيانات

SQLite هي الافتراضية لتسهيل الديمو. يتوفر إعداد PostgreSQL مجاني عبر Docker في `compose.yaml`؛ خطواته موضحة في README الإنجليزي. لم يُختبر تشغيل PostgreSQL في بيئة البناء.

## عرضه في السيرة الذاتية

يمكنك عرض المشروع عبر GitHub وصور أو فيديو ديمو دون استضافة مدفوعة. المشروع غير منشور على الإنترنت حاليًا. استخدمي شرحًا دقيقًا: Backend بـ FastAPI، حسابات وقاعدة بيانات، معالجة ملفات، استرجاع نصي مع مراجع، واختبارات وتتبع تقدّم.

اقرئي [دليل العرض](DEMO.md) و[README الكامل](../README.md) للتفاصيل.


## الديمو والمشاركة

أضيف زر دخول تجريبي مباشر لكل زائر، مع جلسة مستقلة لمدة ٢٤ ساعة. نسخة المشاركة تستخدم قاعدة بيانات منفصلة. [دليل رابط المشاركة المؤقت](SHARING.md) يوضح طريقة تشغيله وحدوده.

نجحت ٢٨ حالة اختبار آلية و٢١ فحصًا مباشرًا عبر رابط HTTPS. [تقرير الباك إند](BACKEND-VALIDATION.md).
